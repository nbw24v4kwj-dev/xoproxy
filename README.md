## 开发者友好

提供完整 API 文档，支持 C++、Go、Node.js、PHP、Java、Python 等主流语言的示例代码，几行代码即可接入现有系统。示例（SOCKS5 代理）：

```bash
curl -x socks5://your-proxy-ip:port https://ipinfo.io/json
```

```python
import requests

proxies = {
    "http": "socks5://your-proxy-ip:port",
    "https": "socks5://your-proxy-ip:port",
}

resp = requests.get("https://ipinfo.io/json", proxies=proxies, timeout=10)
print(resp.json())
```
